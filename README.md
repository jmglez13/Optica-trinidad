# Óptica Trinidad — Talavera de la Reina

Sitio web estático (multipágina) de Óptica Trinidad.

## Estructura
- `index.html` — página de inicio.
- Páginas: `novedades`, `gafas-sol`, `gafas-ver`, `sol-mujer`, `sol-hombre`, `ver-mujer`, `ver-hombre`, `lentillas`, `servicios`, `salud`, `nosotros`, `blog`, `contacto`.
- Artículos del blog: `art-2020`, `art-miopia`, `art-lentilla`, `art-revision`, `art-progresivas`, `art-ortok`.
- `styles.css` — estilos (compartido por todas las páginas).
- `script.js` — JavaScript (menú móvil, filtros, animaciones).
- `IMAGENES/` — imágenes (organizadas por marca: `chanel`, `gucci`, `woow`, `life loft`).

## Publicar con GitHub Pages
1. Sube todos estos archivos a un repositorio de GitHub.
2. En el repositorio: **Settings → Pages**.
3. En *Source* elige la rama (`main`) y la carpeta `/ (root)`.
4. Guarda. En unos minutos la web estará disponible en la URL que indique GitHub Pages.

No requiere ningún servidor ni compilación: son archivos estáticos (HTML, CSS, JS e imágenes).
